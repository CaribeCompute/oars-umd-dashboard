# Original GeoTIFFs

Place original `.tif` / `.tiff` files and associated metadata here. Raster files in this directory are ignored by Git and are not served by the website. Keep a separate durable backup of the originals.

Include the source, acquisition year, coordinate system, units, NoData value, bands/classes and intended color legend. Tell us whether each dataset may be public.

Adding a file here does not display it automatically. See [the GeoTIFF guide](../../docs/local-geotiffs.md) for preparation and registration of a public map layer.
