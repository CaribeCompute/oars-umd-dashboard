# OARS walkthrough narration

## 00:00 Welcome to OARS

Welcome to OARS, Options for Adapting to Rising Seas. This walkthrough introduces the current dashboard through three demonstration accounts: landowner, agency, and extension officer. We will explore the available workflows and distinguish working features from areas still under development.

## 00:12 Create an account

Start by creating an account and selecting your role. Registration collects the details required for that account, including structured address information when applicable. Landowner, agency, and extension officer accounts do not require administrator approval. Follow any email verification instructions before signing in.

## 00:26 The landowner workspace

After signing in, the landowner sees a personalized workspace. Bay View Farm is our demonstration property. From this screen, you can manage property information, open an assessment, explore programs, or enter the property map. Each property has its own saved record.

## 00:38 Maintain property details

The property editor records the name, location, land use, acreage, and registry reference. Address validation helps locate the property on the map. Review these details before saving, because assessments and map records are connected to the selected property.

## 00:50 Explore spatial context

In GIS, choose a property and explore available basemaps and layers. Sources include soils, wetlands, land cover, high tide flooding, and a sea level rise scenario. Adjust opacity and read the source notes. These layers provide context, not a property diagnosis.

## 01:03 Draw and record observations

Select Draw boundary and add at least three points. Use Add observation to place a flooding or salt patch marker, then record the observation date and notes. Signed in property maps save automatically. Public map drawings, like this example, are temporary.

## 01:14 Keep field evidence

Below the saved property map, choose an observation to upload its original field photos. Supported files are JPEG or PNG, up to ten megabytes each. Download or delete photos from the same panel. GeoJSON export provides the boundary, observations, and notes for deliberate sharing.

## 01:27 Report a salt patch

To report a salt patch, use the action beneath that marker's notes. Review your name, county, exact location, and the notes you want to share. Continue to Survey123, attach your own patch photo, complete the CAPTCHA, and submit there. Opening the form does not submit it.

## 01:40 Start the assessment

The guided assessment begins with the property. Confirm its location, land use, and your relationship to the land. A link opens the saved property GIS when you need to review boundaries or observations before continuing.

## 01:50 Describe visible conditions

Next, choose descriptions for plant condition, soil appearance, and water or drainage. The field photo guide helps explain visible features. The current score remains a demonstration. It is not a validated scientific determination or a forecast of the property's future.

## 02:01 Choose your priorities

Choose the goals that matter most, such as continuing agricultural use, protecting habitat, preserving income, or maintaining the property's legacy. Their order records your priorities for planning conversations. At present, these goals do not automatically rank the program examples.

## 02:14 Review the starting points

Results summarize the preliminary score, property information, goals, and examples from the OARS shortlist. The examples are selected by land use rather than a validated matching algorithm. Open the program details and confirm eligibility, availability, and funding with the provider.

## 02:27 Download a useful report

Use Print or download results to create a PDF. It includes the assessment, program examples, and a coordinate reference map of saved boundaries and observation pins, with optional photos. Save GIS changes first. The report map is not a satellite screenshot. Save assessment separately to retain answers.

## 02:41 Browse the OARS database

The program catalog is available publicly and after signing in. It contains three hundred seventeen source records from the supplied OARS workbook. These are not all unique programs: county specific entries and records repeated in different source sections remain traceable.

## 02:52 Narrow the catalog

Search for a program, practice, agency, or topic. Combine land use, location, resource type, and shortlist filters to narrow the list. Switch to the comparison view when helpful, and use Show more to load additional matching records.

## 03:03 Inspect provider details

Each detail page presents the information supplied in the workbook, including eligibility, supported practices, assistance, contacts, limitations, and provider links when available. The worksheet and row identify the source. Blank source fields remain unknown instead of being filled with guesses.

## 03:16 Learn from field photos

The field guide includes farm and forest photographs and draft scorecards. Select a photo to enlarge it or open the original. Supplied stage labels and credits are preserved. Additional observations without a stage are clearly marked, and a photograph alone does not confirm salinity.

## 03:28 The agency workspace

The agency demonstration account opens a program management workspace with a profile summary and assistance program list. Draft and published labels illustrate the intended workflow. This editor is currently a prototype, and its session changes do not publish into the shared OARS workbook catalog.

## 03:40 Prepare a program listing

New program and Edit open the listing form. It includes a name, description, application method, status, and an external application link where applicable. Use this screen to review the planned agency experience. Persistent publishing and a working profile editor still need implementation.

## 03:53 The officer workspace

The extension officer account opens Landowner assistance, organized around assigned landowners. This local setup currently reports that server side account administration is not configured. We can show the screens, but should not claim that portfolio management is operational until that configuration is completed.

## 04:06 Assisted landowner onboarding

The Create landowner tab is designed for assisted onboarding. It collects contact information, a farmer identifier, property details, and a structured address. Once configured, this workflow is intended to create and assign the account with an audit record. No account is created in this demonstration.

## 04:20 Prepare applications with consent

Program applications provides fields for the landowner, agency, program, assessment reference, and preparation notes. The workflow distinguishes a saved draft, recorded consent, and marking an application submitted. It does not automatically send an application to an external provider. Live officer testing remains necessary.

## 04:34 Help is built into OARS

Use Take a tour for a repeatable introduction to the current screen. Back, Next, and exit controls let you move at your own pace. FAQs explain account access, map saving, reporting, and common limitations. The tour never changes or submits your records.

## 04:46 Ready for a guided pilot

OARS now brings property records, spatial context, field evidence, program information, and reports into one workflow. Use demonstration data for a guided pilot, and report issues. Scientific scoring, personalized eligibility matching, agency publishing, and officer configuration still need completion before claiming a fully operational service.
